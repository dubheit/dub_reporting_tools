Framework · Plugin architecture

Reporting Base

The foundation module for the Dubhe Reporting Tools suite. A clean plugin interface that lets Odoo delegate report rendering to external engines — Carbone, BIRT, iLovePDF, and more — without stepping on each other's toes.

Contact Dubhe Visit dubhe.it
Why this module

One hub, many engines

Odoo's native QWeb reports work well for simple layouts, but break down on pixel-perfect Word/Excel templates, enterprise PDF processing, or data-heavy analytical reports.

dub_reporting_base introduces a plugin interface so any number of external engines can coexist. Install only the engines you need.

Engine routing Shared utilities Unified settings Zero runtime deps
What's inside

A tiny framework with clear extension points

Engine routing

Extensible _render() dispatcher on ir.actions.report. Each engine adds its own type.

Shared utilities

Template validation, MIME detection, error wrapping, structured logging — reusable across engines.

Backend JS framework

One shared report-action handler for all engines. Consistent UX no matter which engine rendered the file.

Unified settings section

Each engine plugs its config panel under a single Reporting block in Odoo settings.

Safe pre-init hook

Adds engine-neutral schema columns on install, no database downtime or partial migrations.

Zero external deps

Depends only on base and web. No Python libraries, no system tools required.
