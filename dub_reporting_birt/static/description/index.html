When QWeb is not enough

For the reports your controller can't write in HTML

Cross-module aggregations, 10-join aged receivables, KPI dashboards, crosstabs, charts — BIRT is what data teams reach for when QWeb starts to buckle.

This module uploads your .rptdesign templates to a BIRT engine over HTTP and streams back PDFs, DOCX, XLSX or HTML. Works beautifully with a BIRT Docker container next to Odoo.

What's inside

Engineered for data-heavy reporting

HTTP template mode

Odoo hosts the template, BIRT fetches it at render time. No file-system sync issues.

.rptdesign editor

Design in the free Eclipse BIRT Designer desktop tool with live Postgres previews.

Multiple formats

PDF (most common), DOCX, XLSX, HTML. One template, many outputs.

JDBC configuration

Per-company connection strings, versioned output settings, multi-tenant-friendly.

Cross-module reports
