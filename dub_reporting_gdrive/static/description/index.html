Google Drive Integration

Sync templates from Google Drive to Odoo

Key Features

Google Drive File Picker
Browse and select templates directly from Drive

Automatic Sync
Webhook notifications when files change

Google Docs Support
Export Google Docs/Sheets to DOCX/XLSX

Two-Way Sync

Download from Drive
Sync templates from Google Drive to Odoo

Upload to Drive
Save modified templates back to Drive

Push Notifications
Real-time sync via Google Drive webhooks

Authentication Options

Service Account
Server-to-server authentication for shared drives

OAuth2 Per-User
Access user's personal Drive files

Easy Configuration

Configure Google API credentials in Settings > Reporting Tools > Google Drive

Requirements

Google Cloud Project with Drive API enabled
dub_reporting_base module (included as dependency)
Python libraries: google-api-python-client, google-auth
